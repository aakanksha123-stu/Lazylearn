# 📚 LazyLearn

**LazyLearn** is a full-stack mobile learning application built to provide students with a simple, convenient, and organized way to learn and access educational content.

The application uses **React Native** for the mobile frontend and **Django** for the backend, creating a complete mobile learning platform with a modern user interface and a powerful server-side system.

## 🚀 Features

* 📱 **Cross-Platform Mobile App** – Built with React Native for Android and iOS.
* 📚 **Learning Content** – Provides students with access to educational resources.
* 👤 **User Management** – Handles user accounts and application data through the Django backend.
* 🔐 **Backend API** – Django provides the backend services and API communication.
* 🎨 **Simple & User-Friendly UI** – Designed to make learning easy and comfortable.
* ⚡ **Fast & Organized Learning Experience** – Helps students access learning resources efficiently.

## 🎯 Project Objective

The main objective of **LazyLearn** is to create a convenient digital learning platform where students can access educational resources through a mobile application.

It aims to reduce the complexity of learning by providing an **easy-to-use, organized, and accessible learning experience**.
